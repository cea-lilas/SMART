SMART documentation
====================

This package allows a fast and precise computation of spherical aperture mass maps from the shear
field, defined directly on the celestial sphere. The method SMART does not rely on planar
projections and does not require the reconstruction of convergence maps.

The package offers 3 classes for 4 methods of computing aperture mass, ranging in precision and
computation time.
